CampusEats - Taller de patrones de diseño

Abrir esta carpeta como proyecto Maven en NetBeans con JDK 17 o superior.
Ejecutar la clase com.mycompany.campuseats.CampusEats.
Los archivos estan en datos/ y sus rutas se definen en config/fuentes.json.
Ejecutar desde la raiz del proyecto.

Patrones: Adapter, Factory, Pipes & Filters, Strategy, Repository y Facade.
Metricas: platos mas vendidos, pedidos por hora, ticket promedio.


CampusEats - Design Patterns Workshop

Open this folder as a Maven project in NetBeans using JDK 17 or higher.
Run the class `com.mycompany.campuseats.CampusEats`.
Data files are located in the `datos/` directory, and their paths are defined in `config/fuentes.json`.
Execute from the project root.

Patterns: Adapter, Factory, Pipes & Filters, Strategy, Repository, and Facade.
Metrics: best-selling dishes, orders per hour, and average ticket value.
